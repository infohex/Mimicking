Mimicking：让一个人的话，用另一个人的嗓音实时说出来

说话的内容、语气、节奏都是原来的人；听众听到的嗓音，是你指定的那个人。只需要那个人几秒钟的录音，不需要训练。它跑在一台带显卡的普通服务器上，是我们用 Rust 语言重新实现并大幅提速的自有版本。

它解决什么问题

市面上效果好的"零样本变声"模型几乎都是研究代码：用 Python 写成，一张显卡只能带一两路，还要为服务器装一整套开发环境。我们做的事情是把其中效果最好的一个（公开的 Seed-VC 模型）按同样的数学原理重新实现，让它快四倍、能同时服务更多人，并且变成一个能直接拷到服务器上运行的独立程序。模型的"知识"（权重）沿用公开发布的版本，我们没有重新训练，所以听感和原版一致。

它是怎么工作的

整个过程每 0.25 秒循环一次，四步。点左侧看每一步。

为什么能快四倍

原版慢，不是因为显卡算不过来，而是因为显卡大部分时间在等指令。Python 每次要给显卡下发两千多条零碎指令，显卡执行每条只要几微秒，但等下一条指令的时间比执行还长。我们做了三件事：

1. 把指令录成"宏"

一次处理要下发的全部指令只录制一次，之后每 0.25 秒直接整段回放，显卡不再等人。

2. 把零碎指令合并

按同一套数学重写了核心网络的计算顺序，两千多条指令合并成不到两百条。效果不变，时间减半。

3. 外围全部用 Rust

音频切块、拼接、重采样、静音判断这些"手工活"不再经过 Python，稳定、可预测，也便于打包成一个独立程序。

数字来自同一台机器（NVIDIA RTX A4000 显卡，16 GB，算力与 RTX 3070 同级）上对同一段语音的实测，原版为公开代码的实时模式。

能支撑多大的规模

"步数"是嗓音显影的精细程度。标准档 10 步效果最好；6 步听感略粗一点，但同样算力能多带一路。

8 路同时通话

延迟：一个必须事先选定的档位

听众听到转换后的声音，比说话人开口晚多久，取决于一个设置：系统在开口"重说"之前，先多听后面多长一段。多听，衔接更自然；少听，回应更快。原版也提供同样的选择。我们导出了两套模型，部署时选一套：

低延迟档（先多听 0.02 秒）：整体约 0.6 秒。

质量优先档（先多听 2 秒）：整体约 2.5 秒。

两条时间轴都不含耳机或声卡自身的延迟（有线约 0.03 秒，蓝牙耳机常见 0.15 到 0.25 秒）。低延迟档接近视频会议的水平，可用于双向对话；质量优先档适合单向场景（播报、配音、直播、把一方的声音转换后送给另一方）。两档之间也可以取中间值，换档只需重新导出一套模型，几分钟完成，不必重新训练。

边界与风险，先说在前面

事项说明
硬件目前只支持 NVIDIA 显卡。其他显卡需要另做一套运行后端，技术上可行但未做。
延迟两档可选：低延迟档约 0.6 秒，质量优先档约 2.5 秒，见上文。接入时按场景选定。
嗓音来源嗓音完全由参考录音决定，录音的音高、年龄感会被带过去；参考录音要清晰、无背景音乐。
模型许可模型权重来自公开发布，其许可为 GPL-3.0；我们的程序代码是自有实现，不含原版代码。对外商用前需要就模型权重的许可做一次法务确认，或改用自训练权重。
语言模型只关心"说了什么声音"，不依赖具体语言，中英文都可；对不常见语言未系统评估。

常见问题

需要给每个目标嗓音单独训练吗？

不需要。给一段 3 秒以上的清晰录音，几百毫秒内就能"记住"这个嗓音，通话中也可以随时切换。

会把说话内容改掉吗？

不会。它只换嗓音，字句、语速、停顿、情绪起伏都保留。它不做翻译，也不理解语义。

没人说话的时候呢？

有静音检测，安静时输出也安静，不会"无中生有"地发出声音。

一张卡 4 路是怎么算的？

一张卡上的几路是依次处理的，每一路都要等整轮做完才出声，所以整轮时间直接计入每路的延迟。质量优先档每路每块约 50 毫秒，4 路一轮 200 毫秒，不超过 240 毫秒的节拍；低延迟档每路约 28 毫秒，4 路一轮 115 毫秒，余量更大、更稳。再加路数一轮就贴近或超过节拍，延迟翻倍且一有抖动就丢块，所以上限定在 4 路。实测卡是 RTX A4000（16 GB，与 RTX 3070 同级）；两张卡各 4 路，每卡一轮约 120 毫秒。路数随显卡性能线性变化，可以用上面的估算器看。

和原版比，效果有没有打折？

没有。我们用的是同一套模型知识，只是重写了执行方式。客观打分和原版持平或略高，逐环节数值比对一致。

能不能做到像面对面说话一样没有延迟？

完全无感知做不到：系统至少要攒够一小段语音再处理。低延迟档整体约 0.6 秒，和视频会议相当，双向对话可用；质量优先档约 2.5 秒，只适合单向场景。两档之间可以按需要折中。

部署复杂吗？

把一个约 3 GB 的文件夹放到带 NVIDIA 显卡的 Windows 服务器上即可运行，附带的检查命令会校验模型文件完整性。
